# Thai Registration AI — Web Prototype

เว็บแอปต้นแบบสำหรับอัปโหลดภาพเล่มทะเบียนรถยนต์ไทยและคัดกรองคุณภาพภาพ/อ่านข้อความ OCR

## วิธีทดลองบนเครื่อง
1. ติดตั้ง Python 3.11
2. ติดตั้ง Tesseract OCR พร้อมภาษา Thai และ English (ถ้าต้องการ OCR)
3. เปิด Terminal ในโฟลเดอร์นี้
4. รัน:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   streamlit run app.py
   ```
5. เปิด `http://localhost:8501`

## วิธีเผยแพร่เป็นเว็บไซต์
ทางเลือกที่ง่ายสำหรับต้นแบบคือ Streamlit Community Cloud:
1. สร้าง GitHub repository ใหม่
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง repository
3. เข้า https://share.streamlit.io/ และเชื่อมบัญชี GitHub
4. เลือก repository และไฟล์ `app.py` แล้ว Deploy
5. `packages.txt` จะใช้ติดตั้ง Tesseract และชุดภาษาในระบบ build ของ Streamlit Cloud

หมายเหตุ: เว็บไซต์สาธารณะประมวลผลไฟล์บนเซิร์ฟเวอร์ของผู้ให้บริการโฮสต์ อย่าใช้เอกสารจริงที่มีข้อมูลส่วนบุคคลจนกว่าจะมีระบบยินยอม การจำกัดสิทธิ์ การเข้ารหัส และนโยบายลบไฟล์ที่เหมาะสม

## ขอบเขตการทำงาน
- อัปโหลด JPG/PNG/WEBP ได้หลายภาพ
- วัดความละเอียด ความคมชัด ความสว่าง และ contrast
- แสดง EXIF ที่ยังอยู่ในไฟล์
- OCR ไทย/อังกฤษ หากติดตั้ง Tesseract พร้อมภาษา
- เปรียบเทียบค่าบางฟิลด์จากข้อความ OCR ระหว่างภาพ
- ดาวน์โหลดรายงาน TXT

## ข้อจำกัด
นี่เป็นระบบคัดกรอง ไม่ได้มีโมเดลที่ผ่านการฝึกเพื่อแยกเล่มแท้/ปลอม ไม่มีฐานข้อมูลกรมการขนส่งทางบก และไม่สามารถยืนยันเอกสารแท้/ปลอมได้จากภาพเพียงอย่างเดียว ค่า image metrics ไม่ใช่คะแนนความแท้ และ OCR อาจอ่านผิดได้

การพัฒนาโมเดลตรวจจับการปลอมแปลงอย่างจริงจังต้องมีชุดข้อมูลเล่มแท้/ปลอมที่ได้รับการยืนยันแหล่งที่มาและสิทธิการใช้งาน รวมถึงการทดสอบกับเอกสารจริงโดยผู้เชี่ยวชาญ
